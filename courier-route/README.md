# מסלול שליח: אב-טיפוס

אפליקציית רשת לשליח יחיד. היא נפתחת בדפדפן של הטלפון ולא דורשת התקנה מחנות האפליקציות.
השליח מזין את הכתובות (בהקלדה, בהדבקת רשימה או בצילום תווית), והאפליקציה מחשבת את סדר המסירה
הקצר ביותר, מציגה את סדר ההעמסה לרכב ופותחת את Waze לכל עצירה.

## מה יש בגרסה הזו

| יכולת | איך זה עובד |
|---|---|
| הזנת כתובות ידנית | שדה כתובת אחת, או הדבקת רשימה (כתובת בכל שורה) |
| צילום תווית + OCR | צילום מהמצלמה. השרת מזהה טקסט בעברית ובאנגלית (Tesseract) ומציע את הכתובת, השם והטלפון. השליח מאשר או מתקן |
| איתור במפה | כל כתובת מומרת לנקודה. כתובת שלא אותרה מסומנת ⚠, ואפשר לתקן אותה או לבחור את המקום ידנית על המפה |
| חישוב מסלול אופטימלי | זמני נסיעה אמיתיים על מפת הכבישים של ישראל (OSRM), וסדר אופטימלי (Google OR-Tools). יוצאים מהמיקום הנוכחי של הטלפון או מכתובת יציאה קבועה |
| סדר העמסה | מוצג הפוך לסדר המסירה: מה שנמסר אחרון נכנס ראשון. מספר העצירה גדול, כדי לכתוב אותו על הקופסה, ויש תיבות סימון "הועמס" |
| Waze | כפתור לכל עצירה שפותח ניווט ישיר ב-Waze |
| סיום יום | מעביר את משלוחי היום לארכיון ומרוקן את הרשימה |

**לא כלול, אבל התשתית מוכנה:** הודעות ללקוחות, חלונות זמן, עדיפויות, נפח רכב, הפסקות, נקודת סיום,
סימון "נמסר / לא בבית", הוכחת מסירה וחישוב מחדש אוטומטי. הפירוט נמצא בסעיף [הרחבות עתידיות](#הרחבות-עתידיות).

## מבנה המערכת

```
טלפון (דפדפן)
   │  HTTPS
   ▼
Caddy  ── תעודת HTTPS אוטומטית
   │
   ▼
API (Python FastAPI) ── SQLite (data/courier.db)
   │        ├─ Tesseract OCR (עברית + אנגלית)
   │        ├─ OR-Tools (סדר אופטימלי)
   │        └─ Nominatim / Google (איתור כתובות, עם מטמון)
   ▼
OSRM ── מפת ישראל מ-OpenStreetMap (מתעדכנת אוטומטית כל שבוע)
```

כל הרכיבים רצים ב-Docker על השרת שלך. בתוכנית KVM 2 (8GB זיכרון) השימוש הוא בערך 1.5 עד 2GB.

# מדריך התקנה בשרת Hostinger (KVM 2, Ubuntu 24.04)

ההתקנה כולה היא בערך 20 עד 30 דקות, ורובה המתנה.

## שלב 1: כתובת לאפליקציה (דומיין)

כדי שהמצלמה והמיקום יעבדו בטלפון, האפליקציה חייבת לרוץ ב-HTTPS, ולכן צריך כתובת. יש שתי אפשרויות:

**אפשרות א': בלי דומיין (חינם, הכי פשוט).** סקריפט ההתקנה יציע כתובת בסגנון `203.0.113.10.sslip.io`, כאשר המספרים
הם כתובת ה-IP של השרת. זה עובד מיד ולא דורש שום הגדרה. אפשר לעבור לדומיין משלך בהמשך.

**אפשרות ב': תת-דומיין משלך** (למשל `route.mydomain.co.il`):
1. ב-hPanel של הוסטינגר: **VPS → הבחירה בשרת**, ומעתיקים את כתובת ה-IP מתוך **Overview**.
2. באזור ניהול ה-DNS של הדומיין (אם הדומיין בהוסטינגר: **Domains → הדומיין → DNS / Nameservers**) מוסיפים רשומה:
   - Type: `A`
   - Name: `route`
   - Points to: כתובת ה-IP של השרת
   - TTL: ברירת המחדל
3. מחכים 5 עד 30 דקות שהרשומה תתעדכן.

## שלב 2: כניסה לשרת

אפשר בשתי דרכים:

- **מהדפדפן:** ב-hPanel: **VPS → השרת → Browser terminal** (או **Terminal**). נפתח מסוף כ-root.

הסיסמה היא סיסמת ה-root שהגדרת ב-hPanel. אם שכחת אותה, מאפסים ב-**VPS → Settings → Root password**.

## שרת עם CloudPanel או nginx קיים

אם בשרת כבר רץ nginx על פורטים 80/443 (למשל CloudPanel, שמנהל אתרים אחרים), הסקריפט לא נוגע בו.
במקרה כזה האפליקציה רצה בכתובת פנימית `http://127.0.0.1:8090` (המספר המדויק מופיע בסוף ההתקנה
ובשורה `API_PORT` בקובץ `.env`), ו-nginx הקיים מעביר אליה את התת-דומיין ומטפל ב-HTTPS.

### עם CloudPanel

1. נכנסים ל-CloudPanel: `https://IP_של_השרת:8443`, או מ-hPanel דרך **VPS ← Manage panel**.
2. **Sites ← Add Site ← Create a Reverse Proxy**, וממלאים:
   - **Domain Name:** `route.s2uthemes.com`
   - **Reverse Proxy Url:** `http://127.0.0.1:8090`
   - **Site User / Password:** כל שם וסיסמה. זה משתמש מערכת של CloudPanel, לא הסיסמה של האפליקציה.
   - לוחצים **Create**.
3. **הגדלת גודל ההעלאה** (צילומי תוויות): נכנסים לאתר החדש ← **Vhost**. בתוך הבלוק `server { ... }`
   שמכיל `listen 443`, מוסיפים שורה:

   ```
   client_max_body_size 15M;
   ```

   ולוחצים **Save**.
4. **HTTPS:** באתר ← **SSL/TLS ← Actions ← New Let's Encrypt Certificate ← Create and Install**.
   התעודה מתחדשת לבד.
5. פותחים בטלפון את `https://route.s2uthemes.com`.

### עם nginx רגיל (בלי CloudPanel)

יוצרים קובץ `/etc/nginx/sites-available/route.conf`:

```
server {
    listen 80;
    server_name route.s2uthemes.com;
    client_max_body_size 15M;
    location / {
        proxy_pass http://127.0.0.1:8090;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

ואז מפעילים ומנפיקים תעודה:

```bash
ln -s /etc/nginx/sites-available/route.conf /etc/nginx/sites-enabled/ && nginx -t && systemctl reload nginx
```

```bash
apt-get install -y certbot python3-certbot-nginx && certbot --nginx -d route.s2uthemes.com
```

## איתור כתובות מדויק יותר עם Google (אופציונלי)

ברירת המחדל היא Nominatim (OpenStreetMap). הוא חינמי, אבל פחות מדויק בכתובות בעברית. כדי לעבור ל-Google:
1. ב-[Google Cloud Console](https://console.cloud.google.com/) יוצרים פרויקט, מפעילים את **Geocoding API**
   ויוצרים מפתח API. מומלץ להגביל את המפתח ל-Geocoding API בלבד.
2. מגדירים תקציב או מכסה יומית ב-Billing, כדי שלא יהיו הפתעות.
3. בשרת מעדכנים בקובץ `.env`:

```
GEOCODER=google
GOOGLE_MAPS_API_KEY=המפתח_שלך
```

4. מריצים `docker compose up -d`.

כתובות שכבר אותרו נשמרות במטמון ולא נשלחות שוב. כך שליח אחד נשאר בדרך כלל בתוך המכסה החינמית של Google,
אבל כדאי לבדוק את המחירון העדכני שלהם.

## הרחבות עתידיות

הקוד בנוי כך שאפשר להוסיף את היכולות האלה בלי לשנות את מבנה הנתונים:

| יכולת | איפה מתחילים |
|---|---|
| חלונות זמן, עדיפויות, נפח רכב, הפסקות | `api/app/services/constraints.py`: מוסיפים מחלקת אילוץ ל-`build_constraints()`. השדות `time_window_start/end`, `priority`, `volume` ו-`service_minutes` כבר קיימים בטבלת `stops` וב-API |
| נקודת סיום (חזרה הביתה / למחסן) | כבר נתמך ב-optimizer וב-API (`end` ב-`/api/route/plan`). נשאר להוסיף שדה בהגדרות ובממשק |
| סימון "נמסר / לא בבית" | ה-API `POST /api/stops/{id}/status` קיים ומפעיל את האירוע `stop_status_changed`. נשאר להוסיף כפתורים בממשק |
| חישוב מחדש של המסלול | חישוב המסלול כבר כולל רק משלוחים בסטטוס "ממתין" ומתחיל מהמיקום הנוכחי. נשאר לחבר אותו לאירוע `stop_status_changed` |
| הודעות ללקוחות (SMS / WhatsApp) | `api/app/services/notifications.py`: מממשים ספק חדש. ב-`events.py` יש דוגמה כבויה שמחוברת לאירוע `route_planned`, כולל זמן הגעה משוער לכל עצירה |
| הוכחת מסירה (צילום) | השדה `proof_photo_path` קיים בטבלה |
| כמה שליחים | להחליף SQLite ב-PostgreSQL (משתנה `DATABASE_URL`) ולהוסיף משתמשים. OR-Tools תומך בכמה רכבים |
