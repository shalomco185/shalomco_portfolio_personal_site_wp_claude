      עדיין אין משלוחים. הזן כתובת או צלם תווית.

        עוד לא חושב מסלול. הוסף משלוחים ולחץ "חשב מסלול".

        איך להעמיס: מעמיסים לפי הסדר מלמעלה למטה. הראשון ברשימה נכנס ראשון (הכי עמוק ברכב) כי הוא נמסר אחרון. כדאי לכתוב על כל קופסה את מספר העצירה שלה.

          סדר ההעמסה יופיע אחרי חישוב מסלול.

          רשימת לקוחות

          לקוח מזוהה לפי מספר הטלפון. כל משלוח עם טלפון מוסיף או מעדכן לקוח אוטומטית.

          טוען...

          נקודת יציאה

          בחישוב המסלול האפליקציה מנסה קודם את המיקום הנוכחי של הטלפון. אם אין גישה למיקום, היא משתמשת בכתובת הזו (למשל מחסן חברת המשלוחים).

          מראה

          "אוטומטי" עובר לכהה כשהטלפון במצב כהה. הבחירה נשמרת בטלפון הזה.
