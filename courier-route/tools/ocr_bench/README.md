# מדידת דיוק ה-OCR של תוויות

כלי פיתוח שמייצר תמונות תווית מציאותיות (זווית, טשטוש, תאורה לא אחידה, תווית רחוקה)
ומודד באחוזים כמה פעמים הכתובת הנכונה זוהתה. משתמשים בו לפני ואחרי שינוי ב-OCR.

```bash
cd tools/ocr_bench
python gen.py            # 36 תמונות רגילות
python gen.py --hard     # 36 תמונות קשות (הטיה, טשטוש חזק, תווית רחוקה)
python bench.py ../../api meta.json
python bench.py ../../api meta_hard.json
```

תוצאות בגרסה 10: רגילות 36/36, קשות 36/36 (לפני השיפור: 17/36 ו-13/36).
